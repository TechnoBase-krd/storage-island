# Storage Island

Support and privacy pages for **Storage Island**, the Mac App Store utility by TECHNOBASE that keeps your free disk space in sight.

- Support: https://technobase-krd.github.io/storage-island/
- Privacy Policy: https://technobase-krd.github.io/storage-island/privacy.html

Questions or problems? [Open an issue](https://github.com/TechnoBase-krd/storage-island/issues/new).

The pages are plain HTML served by GitHub Pages from the `main` branch.
